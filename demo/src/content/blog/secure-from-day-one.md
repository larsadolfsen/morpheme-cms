Security isn’t something you have to remember to switch on. It’s how your site is built.

**On every site**

- [x] A Content Security Policy on every page: only the page’s own scripts run
- [x] Apps can only load from the addresses they declare
- [x] The cookie banner asks before any analytics or ad cookies are set
- [x] Your privacy policy’s cookie list keeps itself up to date
- [x] Your sign-in is a cookie only your site’s server can read

## Fast because it’s finished

Pages are built before anyone asks for them, and Cloudflare serves them from near each visitor. There’s nothing to compute when a page opens, and nothing to attack.

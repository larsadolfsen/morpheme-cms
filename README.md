# Interstellar CMS

An editor for websites built with [Astro](https://astro.build) and run on [Cloudflare](https://www.cloudflare.com):
the site's owner edits pages, posts, pictures and settings in the browser, and every save is one commit on GitHub.

The CMS is being moved here from the site it was first made for. Until the first version is published, this
repository has nothing to install.

When it is ready, it will be:

- **`@interstellarcms/cms` on npm**: the editor, the standard theme, the Worker and the scripts every site uses;
- **a starter** with a _Deploy to Cloudflare_ button, which sets up a new site on your own Cloudflare account.

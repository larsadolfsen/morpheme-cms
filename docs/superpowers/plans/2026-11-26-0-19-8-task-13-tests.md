- **The score ring (EP1) keeps CS2's colours,** the PageSpeed colours, which the plan keeps because they imitate PageSpeed's own ring; it
  becomes the theme's circular progress indicator with those tones. CS1 is not changed.

- **The side sheet "On this page" marks the section in view as M3's navigation drawer marks its active item** (an active indicator in

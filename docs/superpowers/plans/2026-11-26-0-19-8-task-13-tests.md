that touches what task 1 (items inline), task 8 (*Danger*) or task 14 (carousels) changes waits for that task's pull request to be
merged and builds on it.

**Values.** The M3 values below are from m3.material.io: the pages named under *Source* and M3's published token data (read
20 Nov 2026). Where a component has an Expressive variant, the Expressive value is the one given (skill `material-3`, rule 4).
One correction to the plan follows from it: M3 Expressive's standard menu is `surface-container-low`, not `surface-container`
(baseline), and the theme's Menu already uses `surface-container-low`.

**Every batch's pull request also:** reads the M3 pages of the parts it changes with Playwright and names them; removes the deviation
entries it ends; leaves no own `@keyframes`, `cubic-bezier`, weight `600`, `#fff`, grey, `color-mix` (except state layers and
shadows), opacity for a disabled state or override of a part's `--mo-comp-*` token in the screens' CSS (`src/*.css`, outside the page
and post editor's bar and menus); keeps `check:screens`, `check:themes` and `check:a11y` green; has the before and after screenshots and
a release note line.

# 0.16 batch 7: connectors as MCP clients

Repo: morpheme-cms. Master plan: `2026-11-11-release-0-16.md`. Needs batch 1 (the `mcp` field) and batch 5 (the vault key). Spec: mcp part B.

## Task 7.1: credentials and calls

Files: new `worker/mcp-client.js`, D1 migration.

1. Per site and per app credentials in D1, encrypted with `MCP_VAULT_KEY`. Refresh OAuth tokens; a failed refresh marks **Needs sign-in**. Disconnect and uninstall delete them. The browser only learns whether a connection exists.
2. Calls only to `server`'s host and only a listed tool; no redirect to another host; 10 s and 256 KB limits are errors.

## Task 7.2: the app page and the field

Files: `src/` app page, the `choice` field, i18n en-US and da-DK.

1. **Connects to <host>** with the tools, **Connect** (Forbind), **Connected**, **Disconnect**, **Needs sign-in**.
2. A `choice` field with `options.from` (tool, label, value) filled through the Worker.
3. A first-party `worker.js` gets a helper for a listed tool; a third-party `worker` place stays unused.

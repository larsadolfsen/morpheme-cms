# 0.16 batch 5: MCP server, read-only

Repo: morpheme-cms. Master plan: `2026-11-11-release-0-16.md`. Spec: mcp part A. Read-only: no write tool exists in this batch. The owner sees it before batch 6.

## Task 5.1: discovery, registration, tokens

Files: new `worker/mcp-oauth.js`, `worker/index.js` (route lines), `worker/session.js` (reuse `access`).

1. Name the MCP authorization revision built against.
2. `/.well-known/oauth-protected-resource`, `/.well-known/oauth-authorization-server`, dynamic client registration (https or loopback redirects only), `/oauth/mcp/authorize` (consent page, sign-in through `worker/oauth.js`), `/oauth/mcp/token` (code + PKCE, refresh). Tokens are opaque; only hashes are stored (D1).
3. Ask the owner before any D1 migration or live secret.

## Task 5.2: endpoint and tools

Files: new `worker/mcp.js`.

1. `POST /mcp`, Streamable HTTP, behind the `EDITOR_HOST` check. Each call looks up the token, then `access` (cached ten minutes).
2. Tools: `site_info`, `list_content`, `read_content`, `list_apps`, `read_app_settings` (never a secret field).
3. Size, time and per-connection rate limits.

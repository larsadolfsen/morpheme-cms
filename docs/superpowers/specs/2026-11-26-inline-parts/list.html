The List block in the page editor, with the new rules

Every part you can click has a border and is 48px high (icon, label text, supporting text, link). The active part's border turns blue. The blue solid ring is only for keyboard focus. Empty parts ask for an action: Your label, Your supporting text. Only the active row shows its parts; the others are drawn as the site draws them.
